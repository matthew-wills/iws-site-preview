AI and security

An AI model cannot conduct the investigation, but it can help with drafting the report.

When the analysis is strong, the drafting becomes straightforward.

The hard analytical work happens during the investigation: testing each factor against the evidence and recording the reasoning. IWS keeps the evidence, the assessments and the reasoning together, so optional AI drafting works from a record that is already established. The investigator stays responsible for reviewing and approving the report.

1Drafting

How a draft is made, and what checks it

One setting, AI access, decides how every Draft action reaches a model. Free is limited to No AI. Professional, and a Professional trial, also allow Chat and Endpoint.

No AI Free

You write it

You write each paragraph against the record, and the report is the record assembled under your report style's headings. No model is involved and nothing is sent.

Chat Professional

Copy out, paste back

  1. Copy prompt: the record, the grounding rules and an instruction to audit and correct its own draft before replying.
  2. Paste it into a chat tool your organisation has approved for investigation material.
  3. Paste the reply back. It lands as written, marked “Pasted from chat”, with no automatic check.
  4. Read it against the record, and run Check the record on the Draft report tab.

IWS makes no network call. There is no model audit, repair or polish at this tier.

Endpoint Professional

A connected model service

  1. Draft a paragraph, a section, or the whole report. IWS sends the prompt to the model you configured.
  2. Automatically: mechanical checks on a drafted factor paragraph; the audit, within a whole-report run; polish, only if you tick it in Settings.
  3. On demand: Audit against the record, a second model checking each claim; Repair, which resends only the flagged sections; Polish, offered only after the record check and a fresh audit show nothing moved.
  4. Every repair or polish is shown beside the text it would replace before it lands.

Whichever way it was made, a draft carries where it came from (“Drafted by” and the model, or “Pasted from chat”) and is marked out of date when the record under it changes.

Check the record has no model in it, so the same text always gets the same result. It is available at every AI access setting once something is drafted.

2Limitations

A model can write a plausible report that is wrong

The errors read like the truths, so each known failure has a control. None of the controls proves a draft accurate.

“Likely” rounded up to “virtually certain”Check the record compares each confidence word with the test that produced itRun by hand for chat pastes and drafted sections

3Data and security

Where investigation data is kept, and where it can go

IWS keeps investigation records in storage you control. It does not encrypt or automatically anonymise investigation material, so sensitive records should be protected using your organisation's approved storage and access controls.

What IWS stores locally

  • The investigation is one .sfm file of plain, unencrypted JSON, with pasted images and captured files held inside it. Its folder can also hold evidence/, exports/ and, if you turn it on, attachments/. Protect them as you would any sensitive document, including on a shared or synced folder.
  • Opening a captured file writes a plain copy of it to the investigation's evidence/ folder, or to the system's temporary folder when the investigation has not yet been saved to disk.
  • Endpoint settings and any API key are kept in plain text in the app's local settings for that Windows user, not in the Windows credential store. A key is never written into the .sfm, an export or a run log, and IWS attempts to remove it from error messages shown on screen.
  • No telemetry, analytics or crash reporting. With AI access at No AI, nothing about the investigation leaves the computer.
  • Licence requests are separate from AI drafting; what a trial request sends is set out on the Download page.

What may be sent to an AI provider

  • At Chat or Endpoint, the collated record behind the draft: one object, a section or the whole investigation, with its tests, reasoning, timeline, finalised interviews, evidence text and safety reports. Attached files are named, not sent.
  • A protected safety report's text goes with an instruction not to quote it.
  • Transcript speakers appear by role, mapped by the investigator when the transcript is imported. Any other name, including the interview attendee details, a name typed anywhere else in the record or one spoken in a transcript, is sent as written.
  • Testing an endpoint or refreshing its model list sends no investigation content.

What depends on the provider and your organisation

  • Retention, training on your data, logging, staff access and where data is processed are set by the provider's terms. IWS cannot control or verify them.
  • A model on your own computer keeps processing there. A hosted API or gateway receives the content over the internet.
  • AI access is set per computer. An organisation can cap it through an edition pack or enforce it through IT policy; IWS has no central lock.
  • Consumer chat accounts usually sit outside an organisation's data agreements. Use a tool approved for investigation material.

Configuration detail, with what to ask your IT department for, is in the User Guide: Connecting a model.

4Choosing a model

Test a model before relying on it

Drafting and checking a complete report is demanding work, and models vary a great deal. IWS does not sell AI: you connect your own, and its costs are not part of an IWS licence. Before using a model on a live investigation:

  • Draft a finished or fictional investigation, such as one of the case studies, and compare the result against its record.
  • Run Check the record and, at Endpoint, the audit, and read what they flag.
  • Check the confidence words, excluded factors and recommendations by hand.
  • Make sure the model's context holds the whole record without truncating it.
  • Test again when the model, its settings or your report style change.
